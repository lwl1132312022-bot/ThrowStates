# ThrowStates 保姆级伪代码

## 文件结构

```
ThrowStates/
├── main.py                ← 主程序入口 + 主循环
├── config.py              ← 所有可调参数
├── px4_interface.py       ← PX4 飞控通信 (串口, 仅舵机)
├── pinhole_model.py       ← 针孔相机模型 (像素↔米)
├── vision/
│   ├── __init__.py
│   ├── circle_detector.py ← Canny + Contour + fitEllipse 圆检测
│   ├── yolo_detector.py   ← YOLO 桶检测 (可选, 无模型时全帧检测)
│   └── pipeline.py        ← YOLO→圆检测 流水线 + 预设点计算
└── 伪代码.md              ← 本文件
```

---

## 启动方式

```bash
# 纯视觉测试 (不连飞控, 只看画面)
python main.py --sim

# 连飞控 + 舵机 (串口, B1, 高度1.5m)
python main.py --preset 1 --height 1.5

# 舵机专项测试 (不管视觉, 循环触发指定通道)
python main.py --test-servo 7

# 两个预设点都测
python main.py --preset both
```

│     ┌─────────────────────────────────────────────────────┐ │

│     │                                                     │ │
│     │ 4.2.2 YOLO 桶检测 (有模型时)                         │ │
│     │   dets = yolo.detect(frame)                         │ │
│     │     → model(frame, imgsz=800, conf=0.5, half=True)  │ │
│     │     → [{x1,y1,x2,y2,conf,cls,name}, ...]            │ │

│     │                                                     │ │
│     │ 4.2.2' 全帧检测 (无模型时)                           │ │
│     │   bbox = (0, 0, 1280, 720)  // 整张图               │ │
│     │                                                     │ │
│     │ 4.2.3 对每个 bbox 做圆检测                           │ │
│     │   for each bbox:                                    │ │
│     │     circle = CircleDetector.detect(frame, bbox)     │ │
│     │       ├─ 灰度化 cvtColor(BGR→GRAY)                 │ │
│     │       ├─ 高斯模糊 GaussianBlur(3×3)                │ │
│     │       ├─ Canny 边缘 (25/80)                        │ │
│     │       ├─ 形态学闭运算 (5×5椭圆核)                   │ │
│     │       ├─ findContours → 取最大轮廓                  │ │
│     │       ├─ convexHull 凸包 (闭合断裂弧)               │ │
│     │       ├─ 圆度 = 4π×面积/周长² > 0.6 ?               │ │
│     │       ├─ fitEllipse → (cx,cy), (d1,d2), angle      │ │
│     │       └─ radius = (d1+d2)/2                        │ │
│     │                                                     │ │
│     │     # 针孔模型计算真实直径                            │ │
│     │     Z_C = 1.5 + 0.036 - 0.30 = 1.236m              │ │
│     │     diameter_m = (2 × radius_px × Z_C) / fx         │ │
│     │                                                     │ │
│     │ 4.2.4 返回结果                                      │ │
│     │   → [{circle, diameter_m, edge_success, det}, ...]  │ │
│     │   → [+{annotated_frame}]  // 叠加了边缘和检测圆的图   │ │
│     └─────────────────────────────────────────────────────┘ │
│                           ↓                                  │
│     ┌─────────────────────────────────────────────────────┐ │
│     │ 4.3 计算预设点 pipeline.compute_preset_points(1.5)  │ │
│     │                                                     │ │
│     │ 输入: 高度 = 1.5m                                    │ │
│     │                                                     │ │
│     │ Z_C = 高度 + 相机偏移 - 桶高                          │ │
│     │     = 1.5   + 0.036   - 0.30                        │ │
│     │     = 1.236 m                                       │ │
│     │                                                     │ │
│     │ offset_px = 水甁偏移 × fy / Z_C                      │ │
│     │           = 0.056 × 1058.86 / 1.236                  │ │
│     │           = 48 px                                   │ │
│     │                                                     │ │
│     │ zone_radius_px = (投放直径/2) × fx / Z_C             │ │
│     │                = 0.03 × 1059.15 / 1.236              │ │
│     │                = 26 px                               │ │
│     │                                                     │ │
│     │ 输出:                                                │ │
│     │   B1 = (cx, cy - 48) = (638, 307)   ← 图像上方      │ │
│     │   B2 = (cx, cy + 48) = (638, 403)   ← 图像下方      │ │
│     │   投放范围圆半径 = 26px                               │ │
│     └─────────────────────────────────────────────────────┘ │
│                           ↓                                  │
│     ┌─────────────────────────────────────────────────────┐ │
│     │ 4.4 筛选有效检测                                     │ │
│     │                                                     │ │
│     │ valid_circles = [r for r in results                 │ │
│     │                  if r.edge_success AND r.circle]     │ │
│     └─────────────────────────────────────────────────────┘ │
│                           ↓                                  │
│     ┌─────────────────────────────────────────────────────┐ │
│     │ 4.5 对每个预设点找最佳匹配圆                           │ │
│     │                                                     │ │
│     │ 对 B1 (preset_filter=1 时):                          │ │
│     │   for each circle in valid_circles:                  │ │
│     │     dia_cm = circle.diameter_m × 100                │ │
│     │                                                      │ │
│     │     条件1: 直径匹配                                   │ │
│     │       |dia_cm - 15.0| ≤ 2.0  ?                      │ │
│     │       13cm ~ 17cm → OK                               │ │

## 预设点几何 (关键公式)

```
                     图像坐标系 (1280×720)
                     (0,0) ──────────────── (1280,0)
                       │                      │
                       │    B1 (638, 307)      │  ← 上方5.6cm = 北
                       │        ↑ 48px         │
                       │    ● (638, 355)        │  ← 图像中心
                       │        ↓ 48px         │
                       │    B2 (638, 403)      │  ← 下方5.6cm = 南
                       │                      │
                     (0,720) ─────────────── (1280,720)

  B1 = 中心上方: 对应 15cm 桶 (bottle=1), 舵机 AUX7
  B2 = 中心下方: 对应 20cm 桶 (bottle=2), 舵机 AUX8

  投放范围 = 以 B1/B2 为圆心, 半径 26px 的圆 (对应真实 6cm 直径)

  计算公式:
    Z_C = altitude + CAMERA_OFFSET_M - BUCKET_HEIGHT_M
    offset_px = WATER_BOTTLE_OFFSET_M × fy / Z_C
    zone_radius_px = (DROP_ZONE_DIAMETER_M / 2) × fx / Z_C
```

## 投放判定流程图

```
摄像头帧
    │
    ▼
畸变校正 (cv2.remap)
    │
    ▼
┌─ YOLO 模型可用? ─────────────────────┐
│ YES                    │ NO          │
│ YOLO 检测桶 bbox        │ 全帧 bbox    │
└─────────────────────────┘             │
    │                                   │
    ▼                                   ▼
CircleDetector.detect(frame, bbox)
    │
    ├─ 灰度 → 高斯模糊 → Canny → 闭运算 → 轮廓 → 凸包 → 圆度 → fitEllipse
    │
    ▼
compute_diameter(radius, alt)  → 针孔模型算真实直径
    │
    ▼
┌─ 直径匹配? ────────────────────────────┐
│ B1: |dia_cm - 15| ≤ 2                 │
│ B2: |dia_cm - 20| ≤ 2                 │
└───────────────────────────────────────┘
    │ YES
    ▼
取距离预设点最近的圆
    │
    ▼
┌─ dist < zone_radius_px (26px)? ──────┐
│ NO              │ YES                │
│ 继续等待         ▼                    │
│              释放舵机!                │
│              set_actuator(7, 1.0)    │
│              sleep(500ms)            │
│              set_actuator(7, -1.0)   │
│              → 投放完成               │
└──────────────────────────────────────┘
```

## 各参数含义速查

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `TEST_PRESET` | 1 | 测试哪个预设点: 1=B1, 2=B2, "both"=两个 |

## 舵机不动的排查顺序

```
① 用舵机测试模式, 排除视觉问题:
   python main.py --test-servo 7
   → 循环触发 AUX7 3次, 每次开1秒关1秒
   → 如果能动: 问题在视觉判定逻辑
   → 如果不能动: 问题在飞控/硬件

② 检查 PX4 参数:
   COM_PREARM_MODE = 1  (Always)

③ 检查硬件:
   万用表量 AUX 排针电压 (应该有 5V 左右)
   舵机信号线接对了吗? (AUX7 是 AUX 排针的第 1 个)

④ 检查 MAVSDK 是否发送成功:
   控制台会打印 "[舵机] AUX7 -> 1.00  已发送"
   如果打印了但舵机不动 → PX4 侧拦截或硬件问题
   如果没打印 → 代码逻辑没走到 set_actuator

⑤ 在 QGroundControl 里手动测试:
   Widgets → Actuators → 拖 AUX7 滑块
   能控制 → MAVSDK 有问题
   不能控制 → PX4/硬件有问题
```
